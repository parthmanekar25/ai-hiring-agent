⚡ 30-SECOND SETUP

  1. Get Groq API key: https://console.groq.com
  2. Create .env file:  echo "GROQ_API_KEY=your_key" > .env
  3. Install:           pip install -r requirements.txt
  4. Run backend:       python backend/main.py
  5. Run frontend:      streamlit run frontend/app.py
  6. Open browser:      http://localhost:8501

🆘 TROUBLESHOOTING

  Backend won't start?
    → Check: lsof -ti:8000 (kill if running)
    → Or: Change port in backend/main.py

  No GROQ_API_KEY?
    → Create .env with your API key
    → Get key: https://console.groq.com

  Frontend can't connect?
    → Check: Backend running at localhost:8000
    → Try: curl http://localhost:8000/health

  PDF upload fails?
    → Try: Uploading as .txt instead
    → Check: PDF isn't encrypted or corrupted
